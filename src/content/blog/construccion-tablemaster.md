TableMaster nació de la necesidad de organizar diferentes procesos relacionados al tenis de mesa de forma más simple.

## El stack

Usé React para el frontend, Node.js para el backend y PostgreSQL como base de datos, además de python para el modulo de analytics.

Próximamente voy a contar más sobre las decisiones técnicas que tomé.
